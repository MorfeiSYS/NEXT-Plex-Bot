# Plex Zapros Maubot Plugin

Maubot-плагин для поиска фильмов на Plex Media Server и очереди запросов отсутствующего контента в Matrix.

## Возможности

- `!zapros "Название фильма"` — поиск на Plex (X-Plex-Token из config). Год: `"Матрица (1999)"`, `"Матрица" 1999`, `"Матрица" (1999)`, `"Матрица 1999"`, `"Матрица1999"`, `"Матрица(1999)"` — сужает выбор среди найденных по названию (запрос к Plex — только название).
- При нескольких похожих совпадениях — нумерованный список вариантов (лимит `search_results_max`).
- Если фильм есть — ответ запросившему (`reply_mode`: `room` или `dm`).
- Если нет — заявка со статусом **на модерации** (`awaiting_approval`), карточка операторам из `notify_users` (✅ принять / ⛔ отклонить); после одобрения — очередь `pending` и периодическая проверка Plex.
- `!zapros list` — список одобренных ожидающих (`pending`) с карточками модерации (только `notify_users`).
- Операторы: реакция ✅/⛔ на карточке бота или `!zapros accept <id>` / `!zapros reject <id>` (синонимы `approve` / `deny`).
- В YAML-config инстанса: `queue_summary` и `movie_requests` (последние до 25 записей из БД; текстовые поля очищаются от HTML/управляющих символов перед записью в снимок и в БД).
- Вкладка **Database** в Maubot — прямой просмотр SQLite (включая служебную таблицу `sqlite_sequence`).

## Сборка

```powershell
.\build.ps1
```

или

```bash
chmod +x build.sh && ./build.sh
```

Архив: `bild/NEXT.plex-zapros-vX.X.X.mbp` (каталог `bild/` в `.gitignore`).

## Установка

1. Загрузите `.mbp` в [менеджер Maubot](https://docs.mau.fi/maubot/usage/basic.html).
2. Создайте client и instance, привяжите к комнате.
3. В config инстанса задайте:

| Поле | Описание |
|------|----------|
| `plex.base_url` | URL PMS, напр. `http://192.168.1.10:32400` |
| `plex.token` | [X-Plex-Token](https://support.plex.tv/articles/204059436-finding-an-authentication-token-x-plex-token/) |
| `plex.client_identifier` | Идентификатор клиента для Plex API |
| `notify_users` | MXID операторов (уведомления + `!zapros list`) |
| `reply_mode` | `room` — ответ в комнате; `dm` — личные сообщения (в обычной комнате бот только кратко подтверждает отправку в ЛС) |
| `notify_mode` | Операторское уведомление: `dm`, `room`, `both`, `fixed`. По умолчанию как `reply_mode` |
| `notify_room` | Админская комната (`!abc:server`). При `room`/`both`/`fixed` — туда, а не в личку пользователя с ботом |
| `retention_days` | Удалять записи в БД старше N дней (по `created_at`), по умолчанию 90; `0` — отключить |
| `poll_interval_hours` | Пауза между полными циклами опроса pending (по умолчанию 6) |
| `poll_startup_seconds` | Задержка перед первым циклом после старта (по умолчанию 15) |
| `poll_between_pending_seconds` | Пауза между проверками разных pending в одном цикле (по умолчанию 2; 0 — без паузы) |
| `search_limit` | Лимит результатов hubs/search (запрос к Plex) |
| `search_results_max` | Макс. позиций в списке, если на Plex несколько похожих названий (по умолчанию 5) |
| `timezone_offset_hours` | Смещение дат в `!zapros list` относительно UTC (часы), напр. `9` для UTC+9; по умолчанию `0` |
| `title_max_length` | Макс. длина названия в `!zapros` (символов, в БД и Plex); значение в конфиге только 10–100, по умолчанию `100` |
| `list_per_user_max` | `!zapros list`: макс. запросов на одного пользователя (1–50, по умолчанию `5`) |
| `list_users_max` | `!zapros list`: макс. пользователей в ответе (1–50, по умолчанию `10`) |
| `daily_requests_per_user_max` | Макс. **новых** заявок «не найден на Plex» (в т.ч. на модерации) на пользователя за календарные сутки; повтор той же пары title+пользователь не считается; `0` — без лимита; операторы не ограничиваются |
| `daily_found_requests_per_user_max` | Макс. запросов с результатом «найден на Plex» за сутки (`0` — без лимита, иначе 1–1000, по умолчанию `1000`); операторы не ограничиваются |

`queue_summary` и `movie_requests` обновляются автоматически; при ручном сохранении config не удаляйте эти блоки. Не дублируйте в YAML комментарии перед `movie_requests` — при слиянии с `base-config` Maubot может множить строки; лишние комментарии в инстансе можно удалить вручную один раз.

## Команды

```
!zapros "Интерстеллар"
!zapros list
!zapros accept 64
!zapros reject 64
```

`!zapros list` (только операторы) — заголовок и блоки по пользователям; на каждый запрос — отдельное сообщение с кнопками (реакции ✅/⛔). Лимиты `list_per_user_max` и `list_users_max`:

```text
**Запросы фильмов** (только ожидающие)
(до 7 на пользователя, до 10 пользователей)

**Ирина** (Ирина)

#64 [ожидает] «Настройщик» созд. 2026-11-08 15:30, пров. 2026-11-08 15:33; На сервере не найден ✅ | ⛔
```

Уведомление о новой заявке оператору:

```text
Новый запрос контента #64: «Настройщик»
От: @irina:example.com
Комната: Личные сообщения с Ирина
Принять ✅ | Отклонить ⛔
```

## Шифрование (E2EE)

Личные комнаты с ботом обычно зашифрованы. Без настройки crypto maubot **не увидит** `!zapros` в DM (в логах клиента — `Failed to decrypt`).

1. Установите maubot с `[encryption]` (или Docker-образ с crypto).
2. В `config.yaml` maubot задайте `crypto_db` и `crypto_db_pickle_key` (до первого запуска).
3. Создайте клиента через `mbc auth` — нужны **свой** access token и **device ID**, не токен из Element.
4. В UI у клиента должен отображаться fingerprint; перезапустите client/instance.

Проверка: в **незашифрованной** комнате с `reply_mode: room` отправьте `!zapros "тест"`. Если там ответ есть, а в зашифрованном DM нет — проблема в E2EE клиента maubot.

## Проверка

1. Фильм, который уже есть на сервере — мгновенный ответ со ссылкой.
2. Несуществующий фильм — «отправлен на модерацию», карточка операторам; после ✅ — в `queue_summary` и опрос Plex; после ⛔ — удаление из БД и DM пользователю.
3. `!zapros list` от MXID не из `notify_users` — отказ.
4. Смена `plex.token` в UI Maubot — перезагрузка instance при необходимости.
5. Для ускоренного теста опроса временно `poll_interval_hours: 0.02`, добавьте контент на Plex, дождитесь цикла.
6. Лимиты суток: `daily_requests_per_user_max` — только новые pending; `daily_found_requests_per_user_max` — найденные на Plex; операторы не учитываются.
